            Help

            Opening and saving

            • Open (Ctrl+O) or drop a file anywhere on the page. X-Wing .plt files (1705, 1706 or 3410 bytes) and TIE Fighter .tfr files (3856 bytes) are recognised by size. Files stay on your computer; nothing is uploaded.
            • New pilot starts a blank pilot for either game. The TIE Fighter blank matches a pilot created in the 1994 and 1998 games. The X-Wing blank is based on a rookie pilot and the original premade pilots, and has not been checked against a pilot created in the game itself.
            • Save (Ctrl+S) writes over the file in browsers that allow it (Chrome, Edge); otherwise it downloads a new copy and your original is untouched. Save as (Ctrl+Shift+S) always writes a new file.
            • Backup original downloads the file as it was opened (.bak) before the first in-place save.
            • Restore lists the 20 most recent files as they were opened, kept in this browser only.
            • Close goes back to the start page and asks first if there are unsaved changes.
            • Files with two halves (TIE Fighter and the 3410-byte X-Wing file) hold the pilot twice; saving writes the active pilot to both halves.

            Editing

            • Use the list on the left to jump between sections. Fields that differ from the opened file are highlighted. Tours and battles are cards you can expand or collapse, each with a status badge and a progress bar; the kill tables have a filter box.
            • Undo (Ctrl+Z) and Redo (Ctrl+Y) cover every edit, bulk action and preset.
            • Changes lists every changed field with its old and new value, a Revert button for each, and Revert all. It also lists warnings, and bytes changed by hand in Compare as unmapped bytes. The two numbers on the Changes button count changes and warnings.
            • Warnings are advice, for example a rank that does not match the score. They never block saving.
            • Number fields stay within the range the file can hold; hover a field for its range and notes. A value already outside the usual range in an opened file is kept and flagged, not changed.
            • Enforce rules (off by default) keeps related values consistent with the game's rules as you edit, and a message lists what it changed; Undo reverts it together with your edit. It does not change values that already break a rule when a file is opened. Rules it cannot enforce stay as warnings: the number on the Changes button, a ! beside the field and the Warnings list; after an enforced edit the message repeats any that still apply to the fields involved.
              • Rank and score: choosing a rank raises the score to what it needs (Flight Officer 20,000, Lieutenant 50,000, Captain 100,000, Commander 250,000, General 500,000) or lowers it just under the next rank; changing the score changes the rank to match. X-Wing keeps Lieutenant, which training can earn.
              • X-Wing: marking a tour Complete fills its operations and sets its medal, and setting a medal marks its tour Complete the same way; clearing the medal of a Complete tour makes it Incomplete. The Kalidor Crescent is raised to the highest level the operation scores qualify for (it is never lowered, since scores may have been cleared). Hits cannot exceed lasers or missiles fired.
              • TIE Fighter: marking a battle Done sets last mission completed to 8; editing kills by type updates total kills. Laser and warhead hits cannot exceed those fired. Secret Order levels 1 to 6 need the guide's score (20,000, 50,000, 100,000, 250,000, 400,000, 800,000): choosing a level raises the score, and lowering the score lowers the level. The guide also asks for missions with secondary goals; the editor warns when too few secondary goals are ticked but does not tick any for you. Values 7 to 9 have no rule.
            • Presets apply a Top Ace pilot or reset every field to a new pilot. Bulk buttons (Mark all complete, Clear scores and so on) change many fields at once and can be undone. Scores are only changed by the buttons that say so.
            • Calculated values shown beside editable ones, such as hit percentages and battle totals, are for reference. Three have a Sync button that stores the calculated value: TIE Fighter total kills (the sum by type), the X-Wing Kalidor Crescent (the level the scores qualify for) and the X-Wing Tour of Duty points (the total of the recorded operation scores; the game's own points do not always match that total, so Sync is a convenience, not a rule). The Keep equal box beside that total recalculates the points after every operation score you change (switching it on sets them to the total now; it is remembered in this browser, and Compare copies do not trigger it).
            • Raw bytes shows the file bytes with an ASCII column and a frozen header of offsets 00 to 0F. Bright bytes belong to an editable field (double-click one to jump to that field); dim bytes are unknown and kept as they are; bytes that differ from the opened file are marked. Click a byte (or its ASCII character) to select it, shift-click or drag for a range, or use the arrow keys (shift extends, Esc clears); the offset, field and value show above the bytes. Go to offset takes hex (0x2E1) or decimal. Hover a byte for its address in hex and decimal. Rows with data only hides rows that are all 00, and Rows with changes only hides rows with no byte changed since the file was opened; use both together to see just the changed data.
            • The name box sets the file name; the games use it as the pilot name.
            • Theme switches between light and dark and is remembered in this browser.

            Comparing two pilots

            • Compare asks for a second file of the same game and shows the two pilots side by side, with the open pilot on the left. Only the fields that differ are listed, grouped like the sections; untick Differences only to see every field, or type in the filter to narrow the list.
            • The arrows between the values copy a field to the left or right file. The arrows on a group heading copy that group's shown differences, and the all buttons in the table header copy every shown difference. Related fields travel together (operations completed and last completed slot).
            • Copies set values exactly as they are in the other file; Enforce rules is not applied.
            • Raw bytes at the bottom of the comparison shows both files byte by byte with an ASCII column; differing bytes are highlighted. The title, tools and column header (file names and 00 to 0F offsets) stay in view while you scroll. Previous and Next (or P and N in the grid) select the next block of differing bytes, Go to offset takes hex (0x2E1) or decimal, and Rows with differences only hides identical rows, and Rows with data only hides rows that are all 00 in both files. Click a byte, shift-click or drag to select a range (arrow keys move, shift extends); hover a byte for its offset, field and both values, and double-click a byte that belongs to a field to jump to it in the table.
            • Copy bytes writes the selected bytes from one file into the other, including unknown bytes; bytes that belong to a field update that field. It is one Undo step. Only each file's pilot part is compared (the backup half of a two-half file is rewritten when you save). Files with different layouts (the 1706-byte original X-Wing against the 1705-byte Collector's file) are compared by offset, so differences after the shift are expected and byte copies are turned off; use the field table for those.
            • Undo and Redo step back through the copies, whichever side they changed. Save writes a side, and each side has its own Save button. Done returns to editing; it asks first if the other file has unsaved changes.
            • Opening files is switched off while comparing.

            X-Wing notes

            • Tours 4 and 5 store their operations in interleaved a/b slots. Operations completed counts a pair once, and the last completed slot is a slot position, not a count. The editor warns when the two disagree.
            • Training levels have no cap of 8; pilots that flew past the eight main levels load and save unchanged.
            • Rank, medal and Kalidor Crescent checks are warnings only.

            TIE Fighter notes

            • Training, per craft: next level (the level picked at the start, counting from 0, so 2 means level 3), highest level completed (2 for a new pilot, 4 earns the training badge) and best score. The game keeps the highest of each; every run is logged in a separate TRAIN.HGH file, which this editor does not open. Only seven craft exist.
            • Objectives are bitmasks counted goal by goal. Slots with no goal seen in the original Top Ace pilots (battles 11 to 13 especially) are dimmed.

            Unknown bytes are kept

            Only mapped fields are written. Every other byte is kept exactly as it was opened, so saving cannot damage data the editor does not understand. The one exception is when you copy bytes in Compare, which can change unknown bytes on purpose. These are the byte ranges no field maps to, read from the field tables.

                Shortcuts

                • Ctrl+O open, Ctrl+S save, Ctrl+Shift+S save as, Ctrl+Z undo, Ctrl+Y redo, F1 help, Esc closes this window.
                • In the raw bytes grids: click or the arrow keys select and shift extends; Esc clears the selection in the normal view. In Compare, N and P jump to the next and previous difference. Ctrl+O is switched off while comparing, and Ctrl+S saves the left file.
