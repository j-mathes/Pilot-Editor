            Help

            Opening and saving

            • Open (Ctrl+O) or drop a file anywhere on the page. X-Wing .plt files (1705, 1706 or 3410 bytes) and TIE Fighter .tfr files (3856 bytes) are recognised by size. Files stay on your computer; nothing is uploaded.
            • New pilot starts a blank pilot for either game. The TIE Fighter blank matches a pilot created in the 1994 and 1998 games. The X-Wing blank is based on a rookie pilot and the original premade pilots, and has not been checked against a pilot created in the game itself.
            • Save (Ctrl+S) writes over the file in browsers that allow it (Chrome, Edge); otherwise it downloads a new copy and your original is untouched. Save as (Ctrl+Shift+S) always writes a new file.
            • Backup original downloads the file as it was opened (.bak) before the first in-place save.
            • Restore lists the 20 most recent files as they were opened, kept in this browser only.
            • Close goes back to the start page and asks first if there are unsaved changes.
            • Files with two halves (TIE Fighter and the 3410-byte X-Wing file) hold the pilot twice; saving writes the active pilot to both halves.

            Editing

            • Use the list on the left to jump between sections. Fields that differ from the opened file are highlighted.
            • Undo (Ctrl+Z) and Redo (Ctrl+Y) cover every edit, bulk action and preset.
            • Changes lists every changed field with its old and new value, a Revert button for each, and Revert all. It also lists warnings.
            • Warnings are advice, for example a rank that does not match the score. They never block saving.
            • Number fields stay within the range the file can hold; hover a field for its range and notes. A value already outside the usual range in an opened file is kept and flagged, not changed.
            • Presets apply a Top Ace pilot or reset every field to a new pilot. Bulk buttons (Mark all complete, Clear scores and so on) change many fields at once and can be undone. Scores are only changed by the buttons that say so.
            • Calculated values shown beside editable ones, such as hit percentages and battle totals, are for reference.
            • Raw bytes shows the file bytes. Bright bytes belong to an editable field; dim bytes are unknown and kept as they are.
            • The name box sets the file name; the games use it as the pilot name.

            X-Wing notes

            • Tours 4 and 5 store their operations in interleaved a/b slots. Operations completed counts a pair once, and the last completed slot is a slot position, not a count. The editor warns when the two disagree.
            • Training levels have no cap of 8; pilots that flew past the eight main levels load and save unchanged.
            • Rank, medal and Kalidor Crescent checks are warnings only.

            TIE Fighter notes

            • Training, per craft: next level (the level picked at the start, counting from 0, so 2 means level 3), highest level completed (2 for a new pilot, 4 earns the training badge) and best score. The game keeps the highest of each; every run is logged in a separate TRAIN.HGH file, which this editor does not open. Only seven craft exist.
            • Objectives are bitmasks counted goal by goal. Slots with no goal seen in the original Top Ace pilots (battles 11 to 13 especially) are dimmed.

            Unknown bytes are kept

            Only mapped fields are written. Every other byte is kept exactly as it was opened, so saving cannot damage data the editor does not understand. These are the byte ranges no field maps to, read from the field tables.
